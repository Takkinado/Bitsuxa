# Спортклуб «БИЦУХА» — сайт продажи абонементов

Flask + SQLite. Из зависимостей нужен только Flask.

## Запуск
```bash
pip install -r requirements.txt
python app.py
```
Откройте http://127.0.0.1:5000 . При первом запуске сама создаётся база `instance/sportclub.db`
(структура — в `schema.sql`) и заполняется демо-данными. Чтобы сбросить базу — удалите файл `instance/sportclub.db`.

## Учётные записи (демо)
| Роль | E-mail | Пароль |
|---|---|---|
| Администратор | admin@sportclub.local | admin123 |
| Тренер | trainer1@sportclub.local, trainer2@sportclub.local | trainer123 |
| Клиент | client@example.com | client123 |

Перед публикацией смените пароли (или задайте `ADMIN_EMAIL` / `ADMIN_PASSWORD` и `SECRET_KEY` переменными окружения до первого запуска).

## Что умеет сайт
**Посетитель:** главная (залы, тарифы, расписание, тренеры — всё из БД), форма «Пробное занятие» (сохраняется в `applications`), регистрация и вход.
**Клиент:** покупка абонемента (карта — демо-оплата, или на ресепшене), заморозка/разморозка, запись на занятия и отмена, редактирование профиля, смена пароля.
**Тренер:** список своих занятий и записавшихся клиентов.
**Администратор** (`/admin`): обзор и выручка, заявки, клиенты (создание, правка, блокировка, сброс пароля, продажа абонемента), абонементы (подтверждение оплаты, отмена с возвратом), тарифы, расписание (с проверкой конфликтов), тренеры, залы.

## Файлы
- `app.py` — маршруты сайта и кабинета; `admin.py` — админ-панель; `auth.py` — вход, роли, CSRF
- `logic.py` — бизнес-правила и проверки; `db.py` — подключение, схема, демо-данные; `schema.sql` — структура БД
- `templates/`, `static/` — страницы и оформление
- `docs/` — ER-диаграмма, актуальный UML (`Спортклуб_UML.mdj`, открывается в StarUML), описание предметной области (.docx)
- `tests/test_site.py` — автотест: `python tests/test_site.py` (использует временную базу)

Фото зала: положите файл `static/img/about.jpg` — он появится в разделе «О клубе».
Онлайн-оплата картой здесь — имитация (платёж проводится сразу); для реальных платежей нужна интеграция с платёжным провайдером.
